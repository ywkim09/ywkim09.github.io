Choosing the next alert to investigate.

Dynamic alert prioritization uses a Hidden Markov Model to represent uncertainty about attacker progress, then applies active learning to select alerts that are expected to make the belief state more informative.

01 / The problem

Investigate the alert that is most useful now.

A stream of security alerts provides only partial evidence about an attack. The system must estimate the attacker's hidden state while deciding which alert should receive scarce analyst attention. A fixed priority can overlook what the current model is uncertain about.

Hidden state

Track uncertain attacker progress

The HMM represents possible states of an attack and maintains a belief distribution over them as alerts are observed.

Analyst query

Spend investigation effort selectively

Active learning chooses an alert for investigation based on its potential to improve the current state estimate, rather than treating every alert as equally informative.

02 / Selection policies

Two ways to value an alert.

The paper proposes complementary policies for choosing which alert to prioritize. One targets uncertainty reduction; the other emphasizes ambiguity in the alert evidence.

Information gain

MaxEntropy

Selects alerts expected to reduce the entropy of the belief over hidden states, aiming to make the attack-state estimate more certain.

Bayesian prioritization

Bayes

Prioritizes ambiguous alerts according to the proposed Bayesian policy, directing analyst attention toward observations that need clarification.

03 / Efficient inference

Reduce the model without losing sight of the attack.

The study reduces both the state space and exploit space used in inference. Dynamic state-space reduction limits computation to the states relevant to the current belief, helping the method remain practical as the modeled system grows.

Reported evaluation

Faster computation with maintained estimation quality

  • Dynamic state-space reduction lowered computation time by up to 85%.
  • The reduction did not cause a significant increase in belief mean-squared error in the reported evaluation.
  • The proposed alert-prioritization methods reduced belief MSE by up to 50% versus the evaluated baselines.

These are maximum results reported in the study, not guarantees for every dataset or deployment.
