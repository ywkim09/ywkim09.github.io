Intrusion detection with the analyst in the loop.

This framework connects alert investigations to sequential intrusion detection: analyst outcomes adapt the model of alert observations, while active learning chooses investigations that help distinguish competing hypotheses.

01 / The challenge

Detection must adapt as analysts investigate.

An intrusion detector must decide whether observed alerts indicate an attack, even though its view of attacker activity is incomplete. Analyst investigation provides valuable feedback, but the system also needs to choose which alerts are most useful to inspect and when enough evidence has accumulated to raise a detection.

Feedback

Learn from investigation outcomes

Past alerts and analyst findings are used to update observation probabilities, so subsequent inference can reflect what investigations have revealed.

Decision

Balance speed and false detections

Detection is framed as sequential testing over competing hypotheses, allowing evidence to accumulate before the system makes a decision.

02 / Framework

Use feedback to guide the next decision.

The framework combines dynamic alert prioritization, analyst investigations, and sequential multi-hypothesis testing over pruned Hidden Markov Models.

01Model hypothesesRepresent possible system and attacker states with pruned HMMs.
02Select an alertPrioritize an investigation for its expected decision value.
03Update observationsIncorporate the analyst's finding into observation probabilities.
04Test sequentiallyAccumulate evidence until a detection decision is supported.

03 / Active learning

Choose queries that separate hypotheses.

Two policies are proposed for selecting investigations in the sequential testing setting. Both use expected information about competing hypotheses, but measure that value differently.

Likelihood-ratio change

Max Ratio

Chooses investigations that maximize the expected change in likelihood ratios between the hypotheses being tested.

Hypothesis distinguishability

Max KL

Prioritizes observations expected to increase the Kullback–Leibler distinguishability between competing hypotheses.

04 / Evaluation

Faster detection in the reported simulations.

The human-in-the-loop policies were evaluated against a static alert-selection baseline. The reported detection-time gains were measured while maintaining a target mean time between false detections.

Reported simulation result

Up to 79% lower detection time

The proposed query strategies reduced detection time by up to 79% compared with the static baseline in the evaluated simulations, under the specified false-detection constraint.

This is the best reported result from simulation, not a guarantee for every data set or operational deployment.
